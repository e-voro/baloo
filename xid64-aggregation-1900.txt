Grouping
--------
0001: original formatting adaptation, plus two PG19 MultiXact reader diagnostic
      casts formerly introduced alongside 0005; safe for 32/64-bit identifiers.
0002: FullTransactionId input/output in place of the Epoch:xid representation.
0003: 64-bit SLRU callers, retaining native PG19 offset behavior.
0004: 64-bit GUC infrastructure and the v67-0012 MSVC reserved-member fix.
0005: core 64-bit IDs, tuple caches/accessors, page layouts/bases, pruning and
      freeze/WAL/VM semantics, full-width locks/logical decoding, HSF H tag,
      future-horizon rejection, age limits, initdb counters, portable formats
      and normal regression coverage. Includes adapted v67-0007/0008/0009/0010.
      Core page layout/accessor and freeze-fallback correctness stays here:
      ordinary xid64 heap operations also require it. Control-data field
      widths/parsing follow the type change; transfer is deferred to 0007.
0006: original README.XID64, preserving its authors. 0007 updates the backend
      conversion and immediate-WAL sections to describe the implemented design.
0007: complete pg_upgrade transfer/conversion paths, source-format detection,
      SLRU/auxiliary conversion, checksums/swap/index invalidation, by-value
      AIO/CREATE DATABASE metadata, backend private-copy conversion, atomic
      pending publication, access gates, immediate WAL and exceptional image
      obligations, legacy no-hints visibility, HOT roots, and their native
      conversion/upgrade/recovery tests and regression helper corrections.
      The shared item comparator and lock predicates are supplied by 0005
      so the core builds without the converter. The converter joins its
      eventual translation unit in 0007; no new runtime change is introduced.
